# 鼠标快捷键：需求与验收

用户授权：补上鼠标快捷切屏，上传前查错并修复；先准备四个侧键及滚轮按下。基线为 8.1.0.0（本地提交 358d946、已发布源码 37f6b6）。

## 已确认边界

Windows 标准鼠标消息只提供两个扩展侧键，另有中键。四侧键设备的额外键可能由厂商驱动输出为键盘键。已告知用户：侧键 1/2 和中键原生接入，侧键 3/4 提供明确的 F13/F14 驱动映射入口，不宣称所有多键设备都可免映射识别。

- R1 当录制原生侧键 1/2 或滚轮按下时，应得到可确认的鼠标候选，支持 Ctrl/Alt/Shift 组合；取消不提交，Windows 键组合和左/右键不作为鼠标热键。
- R2 当选择侧键 3/4 预设时，应明确标为需要驱动映射 F13/F14，并保存真实键盘值；无鼠标驱动配置时不得宣称原生第三/第四侧键已可用。
- R3 已应用的鼠标热键应经过全局输入通道触发全局切屏、组切屏、角色直切或快捷隐藏。命中按下一次只执行一次，重复 down 不重复执行；同一监听有效期间匹配的 down/up 配对拦截，未匹配按钮、移动和滚动透传，不记录轨迹或注入输入。最终解绑/退出应立即释放监听，不为等待抬起保留全局钩子；跨释放的孤立 up 透传且不触发旧动作。
- R4 设置模态窗口期间应暂停运行热键，录制窗口置于正确 Owner/TopMost 层级；挂钩安装失败应报告，键盘录制仍可用；关闭、取消、禁用、回滚和退出后不得执行队列中的旧操作。
- R5 鼠标与键盘混合绑定发生同程序重复或注册失败时，应保留原生效配置和绑定；离线角色不消耗鼠标热键，重上线恢复。鼠标监听不是跨程序独占注册，不保证检测其他软件同一鼠标键。
- R6 旧键盘快捷键、尺寸、布局、动态组及配置复制行为应保持兼容；新鼠标值保存重载正确。左右键的正常操作不可因新功能被占用。
- R7 上传前应通过新增输入状态、录制界面、生命周期、事务、持久化和全部既有回归，并打包独立版本、校验公开资产。真实硬件/驱动及 EVE 游戏验证单独标注，不用模拟通过替代。

基线复现已确认：8.1.0.0 程序组件拒绝 XButton1、XButton2 及其修饰组合，录制也明确拒绝两个侧键。该缺口不能只靠放开输入框解决。
