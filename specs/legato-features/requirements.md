## 验收

- R1 当载入旧版 JSON 时，系统应导入原有五组的按键和角色顺序，不重置尺寸、布局或单角色按键；新模型支持稳定 ID、名称及任意数量的组。空组继续循环所有可用角色。
- R2 当用户新建、改名、删除、组内调序或把角色拖到另一组时，系统应保存对应组状态；跨组拖拽移动角色，手动添加允许同一角色加入多个组。删组／移除不删除游戏或预览配置。
- R3 当角色上线或下线时，分组页应更新状态而保留离线成员；组内可切换预览显示／隐藏，可打开该角色配置复制入口。展示名称不得代替原始窗口标题作为配置键。
- R4 当用户勾选自动收纳未分组角色时，新上线且未加入任何组的角色应进入第一组；手动移除的角色加入排除列表。默认关闭，避免改变已有用户的循环顺序。
- R5 当编辑分组热键后发生内部重复或 Windows 占用时，应提示并恢复之前已生效的完整组集合与按键；保留录键取消、禁止长按重复及置顶弹窗修复。
- R6 配置同步应仅处理所选目录中严格匹配 `core_char_<数字>.dat` 的角色文件。用户必须选择源和目标并确认覆盖；每个目标先成功备份再原子替换，失败保留原文件并逐项报告。不得跟随符号链接／重解析点，不处理账号配置、登录凭据或任意路径，不自动关闭游戏。
- R7 配置同步应支持选择配置目录、本地角色 ID、全选／本组／仅在线筛选与结果／备份路径提示。角色名称联网识别由用户明确点击触发，区分国服／国际服，禁止猜测或跨服回退；无法联网时仍可按本地角色 ID 操作。
- R8 中文为主并保留英文，荣耀海军标识、自由尺寸、多布局和现有快捷功能保持可用。先通过隔离文件与真实窗口生命周期回归，再打包；实际 EVE 游戏与全部多屏 DPI 效果单独标为未实测。
