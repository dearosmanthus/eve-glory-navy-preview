# EVE-O Preview · 荣耀海军定制版

<p align="center">
  <img src="src/Eve-O-Preview/glory-navy-icon.png" width="160" alt="荣耀海军徽记">

面向荣耀海军成员定制的 EVE-O Preview Windows 多开窗口预览与快捷切换工具。

当前版本：`8.1.1.0-glory-navy-mouse`（鼠标快捷键增强版）

本版新增原生侧键、滚轮按下与额外侧键映射入口，详见[鼠标按键说明](MOUSE-8.1.1.0-zh-CN.md)。保留[动态分组与角色配置复制](FEATURES-8.1.0.0-zh-CN.md)、[设置弹窗修复](BUGFIX-8.0.2.30-zh-CN.md)及已有定制功能。

## 下载与使用

请从仓库右侧的 **Releases** 下载最新版 Windows 压缩包，完整解压后运行：

`EVE-O-Preview-Glory-Navy.exe`

不要直接在压缩包内运行，也不建议解压到 `Program Files`。首次启动若遇到 Windows SmartScreen，请先核对发布页提供的 SHA256 校验值。

## 定制功能

- 原生支持侧键 1/2、滚轮按下及 Ctrl/Alt/Shift 组合，录制后显式确认；侧键 3/4 提供需驱动映射 F13/F14 的预设。
- 鼠标可用于全局切屏、组切屏、角色直切和快捷隐藏；默认仍使用原键盘快捷键，不主动占用鼠标按键。
- 自由新建、改名、删除切屏组，不再限制五组；每组可录制多组前进／后退按键。
- 组内拖拽调序、跨组拖拽移动；显示在线／离线／预览隐藏状态，离线角色保留。
- 可选自动收纳未分组在线角色，默认关闭，手动移出的角色不会立即加回。
- 角色游戏配置复制：明确选择并确认后，先备份目标再替换；支持离线本地 ID 和主动联网识别角色名。
- 缩略图最低可调至 `64 × 36`，宽高支持 1 像素步进和尺寸预设。
- 在“快捷功能”页直接录制上一个／下一个窗口、隐藏／显示预览的按键，点击“应用快捷键”立即生效。
- 在“客户端”页为选中的角色设置独立直切按键，支持清除。
- 默认仍使用 `Ctrl + Alt + ←/→` 切屏、`Ctrl + Alt + H` 隐藏／显示预览；每项可恢复默认。
- 本软件内按键重复、键盘被其他软件占用或监听启用失败时显示具体原因，失败恢复原快捷键；长按不会连续乱切。鼠标监听不能检测所有其他软件的同键冲突。
- 支持为单个客户端设置独立缩略图尺寸。
- 支持命名保存、加载和覆盖多套布局。
- 窗口吸附与更灵活的预览位置调整。
- 实验性后台恢复机制：尽量维持已最小化客户端的 DWM 预览刷新，但效果仍取决于 Windows、显卡驱动和游戏渲染状态。
- 重新分类的中文设置界面与荣耀海军品牌图标。

完整的中文使用说明见 [README-cn.md](README-cn.md)，新版操作步骤见 [快捷键增强版说明](HOTKEYS-8.0.2.29-zh-CN.md)。

升级时先退出旧版，完整解压到新文件夹，首次启动前复制原 `EVE-O-Preview.json` 及需要的命名布局 JSON。旧五组会自动迁移；旧版只能识别前五组，回退时请使用升级前备份。压缩包不包含个人配置。

## 安全与合规说明

本程序显示 EVE 客户端缩略图并切换前台窗口，不广播键鼠输入、不注入游戏。新增的配置复制会在用户选择源／目标并确认后写入 `core_char_<ID>.dat`，不处理账号或登录文件；每个目标先备份再原子替换。游戏退出时可能回写旧设置，操作前应自行关闭相关游戏客户端。

鼠标快捷键使用 Windows 低级鼠标监听，仅解码中键/两个标准侧键；不记录轨迹。运行时只有配置了鼠标绑定才安装监听，录制时也会短暂安装。已绑定组合会拦截对应点击，可能替代其他软件原有的中键/侧键操作；未绑定的点击、左右键、滚动和移动透传。

角色名识别仅在用户主动点击并确认后，向所选国服／国际服 ESI 发送角色名称或 ID；不自动跨服查询。不联网也可以按本地 ID 复制。参考二改包仅用于静态功能对照，其代码、DLL 和资源未纳入发布。

使用者仍需自行遵守 EVE Online 当前的 EULA、服务条款和当地法律。本项目与 CCP Games 无隶属或官方认可关系；EVE Online 及相关标识归其权利人所有。

## 从源码构建

要求 Windows 和 .NET 8 SDK：

```powershell
dotnet publish src\Eve-O-Preview\Eve-O-Preview.csproj `
  -c Release `
  -r win-x64 `
  --self-contained true `
  -p:PublishSingleFile=true
```
